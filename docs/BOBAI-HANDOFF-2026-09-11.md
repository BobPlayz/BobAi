# BobAI handoff — 2026-09-13

The public Bob model family is Bob, Forge, Vanta, Echo, Flux, and Vector. Bob Core and runtime identifiers remain internal, and ordinary users do not receive scheduler or runtime registry state through normal model APIs. The admin runtime surface remains protected by the existing admin boundary.

The runtime layer covers the central text profiles and specialist capability set. Bob and Forge share the native model through reference-counted lifecycle management. Vector retrieval, Vanta vision, Echo speech, and Flux image generation have local execution adapters that acquire the matching runtime lease. Specialist workers are loopback-only with per-worker bearer tokens, lazy checkpoint loading, artifact existence checks, bounded request and response handling, and shutdown handling. Echo has a local speech-server boundary for its TTS artifact, with Griffin-Lim reconstruction to WAV; ASR accepts PCM16 WAV directly and uses a reserved CTC blank class with byte tokens offset by one.

BobHS has repository-side scheduling primitives for node registration, heartbeats, capability and model inventory, resource-aware placement, deployment leases, draining, persistent Docker volume declarations, bounded Docker execution, atomic state writes, and lifecycle status updates. The scheduler selection logic has standalone tests. Production database-backed shared state, public TLS ingress, multi-controller coordination, centralized logs, backups, domains, and real multi-node failover remain deployment verification work rather than claims about the local code.

The native training path is designed for long runs. It saves both a latest checkpoint and a best-validation checkpoint, restores the best checkpoint before exporting the final model, supports cosine learning-rate scheduling, gradient accumulation, early stopping controls, and architecture validation, and the evaluator understands the current BOBAI002 model format. Specialist training supports resumable checkpoints and validates ASR target lengths. Specialist dataset preparation creates embedding masks and correct ASR CTC token offsets. Retrieval can now rerank the strongest vector candidates when trained Vector and Vanta reranker checkpoints actually exist, while safely falling back to vector ranking before training.

No model checkpoint is claimed to be trained. The current model architectures are research baselines and their eventual quality depends heavily on dataset size, quality, tokenizer/model design, training time, and hardware. A seven-day run can make sense as an experiment, but there is no honest way to promise that a from-scratch small model will beat every local model simply by running longer. Repository-side training and orchestration are ready for the user's actual dataset and machine; target Windows compilation, actual training, real specialist datasets, broader native codecs, production hosting and environment variables, external security/load verification, and target-hardware performance still require the user's environment.

Before every future commit, roadmap.md and this handoff must both be updated. roadmap.md remains checklist-only and this handoff remains paragraph-only. The next phase after repository-side work is the user's actual Bob training run, followed by specialist training and real artifact/runtime verification.
