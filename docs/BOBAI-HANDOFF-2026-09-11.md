BobAI now presents one user-facing native model rather than separate named model personalities. The same model decides whether to answer directly or request tools, while the tool registry remains an independent policy boundary for permissions, approvals, validation, provider availability, and bounded execution.

The chat path now runs a bounded model-tool loop: Bob selects tools, approved tools execute through a centralized executor registry, tool results are returned as untrusted data to the same model, and Bob can select another tool or produce the final response. Every currently registered tool has a repository-side executor entry. Approval-required tools stop before execution unless a valid short-lived approval is supplied. Provider adapters enforce HTTPS in production, timeouts, bounded streaming response reads, and redirect rejection. Browser and website-test targets now also reject embedded credentials and hosts or resolved addresses in private/link-local ranges.

The user-facing chat path explicitly pins response and tool routing to Bob, and the environment templates no longer expose obsolete separate coding-model or old specialist-name configuration. A global BOBAI_TOOLS_ENABLED switch can disable tool execution and causes the chat loop to fall back to a direct Bob response. Tool-routing validation also fails closed when the global switch is disabled.

The repository tree was corrected after a transient contents-API write replaced the new loop file; the canonical main branch restores the complete loop implementation and keeps the roadmap and handoff aligned in the corrective commit. The repository does not claim that every real provider/local adapter has been verified, nor that the unified model has been trained to a production-quality level. Final datasets, long-running training, real provider verification, target hardware and native-media builds, production transport/database wiring, external security and failure testing, multi-worker target-environment verification, and final release validation remain environment-dependent.
