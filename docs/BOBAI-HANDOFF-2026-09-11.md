# BobAI handoff — 2026-09-12

This pass adds the repository-side local voice and media layer requested for BobAI. BobVoice is now the local TTS orchestration layer around a Piper-compatible executable and local ONNX voice model, with bounded text and WAV output, configurable executable/model paths, command availability reporting, temporary-file cleanup, and shell-free process execution. The existing authenticated `/voice` API now uses this local implementation by default while preserving the provider hook as an optional compatibility override.

Speech-to-text is now implemented through whisper.cpp. BobAI accepts bounded base64 audio at the authenticated voice transcription endpoint, normalizes arbitrary supported input through FFmpeg to mono 16 kHz PCM WAV, invokes `whisper-cli` with a configured model, reads the generated transcript, and cleans up all temporary files. FFmpeg and ffprobe are also exposed through an authenticated `/ffmpeg` API for bounded probing and explicit-format media conversion. Conversion strips metadata by default, supports a constrained format allowlist, optionally extracts audio, and supports bounded image scaling. All local command execution uses Node child-process APIs with `shell:false`, explicit argument arrays, timeouts, and output limits.

The root and API environment templates document the four local command paths plus Piper and Whisper model paths, with PATH-friendly defaults and no cloud media credentials. The API package includes focused command-builder tests and the root `npm test` command runs both the existing security suite and the local media contract suite. The repository contains `docs/LOCAL_MEDIA.md` describing setup, endpoints, limits, and the exact boundary between repository implementation and installed binaries/model weights.

A follow-up hardening pass normalizes nullable and non-object options before local Piper, Whisper, or FFmpeg execution so malformed JSON option values cannot cause avoidable runtime exceptions. The local media integration is therefore provider-free at the application layer and has no new runtime package dependency.
